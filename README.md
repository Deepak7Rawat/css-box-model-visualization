# 📦 CSS BOX MODEL

### A visual demonstration of the CSS Box Model using HTML & CSS

<i>A simple project showing the relationship between margin, border, padding, and content.</i>

</div>

---

## ✦ About

This project demonstrates the **CSS Box Model** through a nested visual layout.

It represents the four main layers:

**Margin → Border → Padding → Content**

---

## ✦ Features

* Visual CSS Box Model demonstration
* Nested container structure
* Margin spacing
* Border styling
* Padding demonstration
* Content area
* Flexbox alignment
* Simple color-based visualization
